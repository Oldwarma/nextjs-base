# SmartCRUD 系统介绍

> 配置驱动的 CRUD 开发系统，减少 60% 重复代码

**SmartCRUD** 是 NextJS Base Framework 的核心特性，通过统一的字段配置自动生成表格、表单、搜索，让你专注于业务逻辑而非重复的 UI 代码。

---

## 🎯 设计理念

### 灵感来源

SmartCRUD 的设计灵感来自 **VK-uniCloud** 的万能表格/表单系统，但针对 Next.js + Ant Design 技术栈进行了全面优化。

```
VK-uniCloud (uni-app)        →        NextJS Base SmartCRUD (Next.js)
├── vk-data-table                     ├── SmartCrudPage
├── vk-data-form                      ├── DynamicFormFields
├── field-types                       └── field-types
└── 配置驱动                           └── 配置驱动
```

## ✨ 核心特性

### 1. 配置驱动

传统方式需要分别定义表格、表单、搜索：

```javascript
// ❌ 传统方式：重复定义 3 次
const columns = [
  { title: 'Name', dataIndex: 'name', width: 200 },
];

const formFields = (
  <Form.Item name="name" label="Name" rules={[{ required: true }]}>
    <Input placeholder="Enter name" />
  </Form.Item>
);

const searchFields = (
  <Form.Item name="name" label="Name">
    <Input placeholder="Search name" />
  </Form.Item>
);
```

SmartCRUD 只需一份配置：

```javascript
// SmartCRUD：一份配置搞定
const fieldsConfig = [
  {
    key: 'name',
    title: 'Name',
    type: 'text',
    table: { width: 200 },
    form: { required: true, placeholder: 'Enter name' },
    search: { enabled: true, mode: 'like' },
  },
];
```

### 2. 类型驱动渲染

根据 `type` 字段自动选择合适的组件：

```javascript
{ type: 'text' }        → Input
{ type: 'textarea' }    → TextArea
{ type: 'number' }      → InputNumber
{ type: 'select' }      → Select
{ type: 'tree-select' } → TreeSelect
{ type: 'switch' }      → Switch
{ type: 'date' }        → DatePicker
{ type: 'datetime' }    → DatePicker (showTime)
{ type: 'array' }       → ArrayField
```

### 3. 搜索自动转换

搜索条件自动转换为 MongoDB 查询：

```javascript
// 用户输入
{ name: 'test', status: 'active' }

// 自动转换（基于 search.mode）
{
  name: { $regex: 'test', $options: 'i' },  // mode: 'like'
  status: 'active',                          // mode: 'exact'
}
```

### 4. 扩展性强

支持自定义渲染、钩子、验证规则：

```javascript
{
  key: 'avatar',
  title: 'Avatar',
  type: 'image',
  table: {
    render: (url) => <Avatar src={url} />,  // 自定义渲染
  },
  form: {
    rules: [                                 // 自定义验证
      { required: true },
      { validator: customValidator },
    ],
  },
}
```

## 🏗️ 架构设计

```
┌─────────────────────────────────────────────────────────┐
│                   SmartCrudPage                         │
│                                                         │
│  ┌────────────────────────────────────────────────┐    │
│  │  Type-Driven Rendering                         │    │
│  │  - field-types.js (字段类型定义)               │    │
│  │  - field-generator.js (字段生成器)             │    │
│  └────────────────────────────────────────────────┘    │
│                                                         │
│  ┌────────────────────────────────────────────────┐    │
│  │  UI Components                                 │    │
│  │  - Table (ProTable)                            │    │
│  │  - Form (DynamicFormFields)                    │    │
│  │  - Search (ProForm)                            │    │
│  │  - Detail (Descriptions)                       │    │
│  └────────────────────────────────────────────────┘    │
│                                                         │
└────────────────────┬────────────────────────────────────┘
                     │
                     │ Server Actions
                     ▼
┌─────────────────────────────────────────────────────────┐
│  crud-action.{resource}.js                              │
│                                                         │
│  - getList (列表查询)                                   │
│  - create (创建)                                        │
│  - update (更新)                                        │
│  - delete (删除)                                        │
│  - getDetail (详情)                                     │
│  - batchUpdate (批量更新)                               │
└─────────────────────────────────────────────────────────┘
```

### 核心组件

1. **SmartCrudPage** - 主组件
   - 管理表格、表单、搜索的状态
   - 调用 Server Actions
   - 处理用户交互

2. **field-types.js** - 字段类型定义
   - 定义所有支持的字段类型
   - 提供 table、form、search、detail 四种渲染方式

3. **field-generator.js** - 字段生成器
   - 根据 fieldsConfig 生成 ProTable 列配置
   - 根据 search.mode 生成搜索转换函数

4. **DynamicFormFields** - 动态表单
   - 根据 fieldsConfig 动态渲染表单字段
   - 处理 tree-select 的数据加载
   - 支持字段联动

## 🔄 数据流

### 列表查询流程

```
用户操作 (搜索/翻页/排序)
    ↓
SmartCrudPage
    ├─ 收集搜索条件
    ├─ 生成 whereJson (generateSearchTransform)
    ├─ 生成 sortJson
    └─ 调用 actions.getList(params)
        ↓
Server Action: getListAction
    ├─ 权限检查
    ├─ 参数验证
    └─ 查询数据库
        ↓
MongoDB
    ├─ find().sort().skip().limit()
    ├─ countDocuments()
    └─ 返回结果
        ↓
SmartCrudPage 更新表格
```

### 创建记录流程

```
用户点击 "Create" 按钮
    ↓
SmartCrudPage 打开表单 Modal
    ├─ 根据 fieldsConfig 渲染表单
    ├─ tree-select 自动调用 action 加载数据
    └─ 用户填写表单并提交
        ↓
表单验证 (前端)
    ├─ required 字段检查
    ├─ rules 规则验证
    └─ 验证通过
        ↓
调用 actions.create(formData)
    ↓
Server Action: createAction
    ├─ 权限检查
    ├─ 数据验证
    ├─ 添加元数据 (id, createdAt, updatedAt)
    └─ 插入数据库
        ↓
SmartCrudPage
    ├─ 关闭 Modal
    ├─ 刷新列表
    └─ 显示成功提示
```

## 💡 使用场景

SmartCRUD 适用于大部分标准的 CRUD 页面：

### 适用场景

- **用户管理** - 用户列表、角色分配
- **内容管理** - 文章、分类、标签
- **商品管理** - 商品、订单、库存
- **系统配置** - 参数配置、字典管理
- **权限管理** - 角色、权限、菜单

### ⚠️ 不太适用

- **复杂表单** - 多步骤、嵌套结构
- **自定义布局** - 特殊的 UI 需求
- **实时交互** - WebSocket、轮询

对于不适用的场景，仍然可以使用 SmartCRUD 的部分功能（如字段配置、搜索转换），同时自定义其他部分。

## 💭 设计哲学

SmartCRUD 的设计遵循以下原则：

1. **配置优于代码** - 用声明式配置替代命令式代码
2. **约定优于配置** - 合理的默认值减少配置量
3. **渐进式增强** - 基础功能开箱即用，高级功能按需使用
4. **开放封闭原则** - 对扩展开放，对修改封闭
