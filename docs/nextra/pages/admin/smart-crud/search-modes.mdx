# 搜索模式详解

> SmartCRUD 支持多种搜索模式，自动转换为 Prisma 查询

搜索是 CRUD 系统的核心功能之一。SmartCRUD 通过 `search.mode` 配置，自动将用户输入转换为 Prisma 查询条件。

---

## 📋 搜索模式总览

| 模式 | 说明 | Prisma 查询 | 适用场景 |
|------|------|-------------|---------|
| `like` | 模糊搜索 | `contains` + `insensitive` | 文本搜索(名称、描述) |
| `exact` | 精确匹配 | `equals` | 状态、分类、ID |
| `in` | 数组包含 | `in` | 多选、标签 |
| `range` | 范围查询 | `gte`, `lte` | 日期、价格、数量 |
| `gt` | 大于 | `gt` | 数字比较 |
| `gte` | 大于等于 | `gte` | 数字比较 |
| `lt` | 小于 | `lt` | 数字比较 |
| `lte` | 小于等于 | `lte` | 数字比较 |

---

## 1️⃣ like - 模糊搜索

### 说明

最常用的搜索模式，用于文本模糊匹配，不区分大小写。

### 配置

```javascript
{
  key: 'name',
  title: 'Name',
  type: 'text',
  search: {
    enabled: true,
    mode: 'like',  // 模糊搜索
  },
}
```

### 转换规则

```javascript
// 用户输入
{ name: 'test' }

// 转换为 Prisma 查询
{
  name: {
    contains: 'test',
    mode: 'insensitive'  // 不区分大小写
  }
}
```

### 使用示例

```javascript
// 搜索名称包含 "iPhone" 的产品
{
  key: 'name',
  search: { enabled: true, mode: 'like' },
}

// 用户输入: "iPhone"
// 匹配结果:
// - "iPhone 15 Pro"
// - "iphone 14"
// - "Refurbished iPhone"
```

### 适用场景

- 用户名搜索
- 商品名称搜索
- 文章标题搜索
- 描述内容搜索

---

## 2️⃣ exact - 精确匹配

### 说明

精确匹配，用于固定值搜索。

### 配置

```javascript
{
  key: 'status',
  title: 'Status',
  type: 'select',
  options: [
    { label: 'Active', value: 'active' },
    { label: 'Inactive', value: 'inactive' },
  ],
  search: {
    enabled: true,
    mode: 'exact',  // 精确匹配
  },
}
```

### 转换规则

```javascript
// 用户输入
{ status: 'active' }

// 转换为 Prisma 查询
{
  status: 'active'
}
```

### 使用示例

```javascript
// 搜索状态为 Active 的商品
{
  key: 'status',
  type: 'select',
  search: { enabled: true, mode: 'exact' },
}

// 用户选择: "Active"
// 只匹配 status === 'active' 的记录
```

### 适用场景

- 状态筛选
- 分类筛选
- 布尔值筛选
- ID 查询

---

## 3️⃣ in - 数组包含

### 说明

用于多选搜索，匹配数组中任一值。

### 配置

```javascript
{
  key: 'tags',
  title: 'Tags',
  type: 'select',
  options: [
    { label: 'Hot', value: 'hot' },
    { label: 'New', value: 'new' },
    { label: 'Featured', value: 'featured' },
  ],
  form: {
    fieldProps: {
      mode: 'multiple',  // 多选
    },
  },
  search: {
    enabled: true,
    mode: 'in',  // 数组包含
  },
}
```

### 转换规则

```javascript
// 用户输入 (多选)
{ tags: ['hot', 'new'] }

// 转换为 Prisma 查询
{
  tags: {
    in: ['hot', 'new']
  }
}
```

### 使用示例

```javascript
// 搜索包含 Hot 或 New 标签的文章
{
  key: 'tags',
  type: 'select',
  form: { fieldProps: { mode: 'multiple' } },
  search: { enabled: true, mode: 'in' },
}

// 用户选择: ["Hot", "New"]
// 匹配包含 'hot' 或 'new' 的记录
```

### 适用场景

- 标签筛选
- 多分类筛选
- 多状态筛选
- 批量 ID 查询

---

## 4️⃣ range - 范围查询

### 说明

用于日期范围、价格区间等范围查询。

### 配置

```javascript
{
  key: 'createdAt',
  title: 'Created Date',
  type: 'dateRange',
  search: {
    enabled: true,
    mode: 'range',  // 范围查询
  },
}
```

### 转换规则

```javascript
// 用户输入 (日期范围)
{
  createdAt: [
    new Date('2025-01-01'),
    new Date('2025-01-31')
  ]
}

// 转换为 Prisma 查询
{
  createdAt: {
    gte: new Date('2025-01-01'),
    lte: new Date('2025-01-31')
  }
}
```

### 使用示例

```javascript
// 搜索指定日期范围内的订单
{
  key: 'createdAt',
  type: 'dateRange',
  search: { enabled: true, mode: 'range' },
}

// 用户选择: [2025-01-01, 2025-01-31]
// 匹配 2025年1月的所有订单
```

### 价格区间示例

```javascript
// 搜索价格在 100-500 之间的商品
{
  key: 'price',
  title: 'Price Range',
  type: 'number',
  search: {
    enabled: true,
    mode: 'range',
    placeholder: 'Min - Max',
  },
}

// 用户输入: [100, 500]
// 匹配 price >= 100 且 price <= 500
```

### 适用场景

- 日期范围筛选
- 价格区间筛选
- 数量范围筛选
- 评分范围筛选

---

## 5️⃣ gt / gte - 大于/大于等于

### 说明

用于数字比较，大于或大于等于某个值。

### 配置

```javascript
{
  key: 'stock',
  title: 'Stock',
  type: 'number',
  search: {
    enabled: true,
    mode: 'gte',  // 大于等于
    placeholder: 'Min stock',
  },
}
```

### 转换规则

```javascript
// gt - 大于
{ stock: 10 }  →  { stock: { gt: 10 } }

// gte - 大于等于
{ stock: 10 }  →  { stock: { gte: 10 } }
```

### 使用示例

```javascript
// 搜索库存大于 0 的商品
{
  key: 'stock',
  search: { enabled: true, mode: 'gt' },
}

// 用户输入: 0
// 匹配 stock > 0 的记录(有库存)
```

### 适用场景

- 库存筛选
- 评分筛选
- 价格筛选
- 数量筛选

## 🔄 组合使用

### 多条件搜索

```javascript
const fieldsConfig = [
  {
    key: 'name',
    search: { enabled: true, mode: 'like' },
  },
  {
    key: 'status',
    search: { enabled: true, mode: 'exact' },
  },
  {
    key: 'price',
    search: { enabled: true, mode: 'range' },
  },
];

// 用户输入
{
  name: 'iPhone',
  status: 'active',
  price: [100, 500]
}

// 转换为 Prisma 查询 (AND 关系)
{
  name: { contains: 'iPhone', mode: 'insensitive' },
  status: 'active',
  price: { gte: 100, lte: 500 }
}
```

### 自定义搜索逻辑

如果需要 OR 关系或更复杂的查询，可以在 Server Action 中自定义:

```javascript
export const getProductListAction = wrapAction('sysQueryProductList', async (params) => {
  const { whereJson = {} } = params;
  
  // 自定义复杂查询
  if (whereJson.keyword) {
    const keyword = whereJson.keyword;
    delete whereJson.keyword;
    
    // OR 查询: 名称或描述包含关键词
    whereJson.OR = [
      { name: { contains: keyword, mode: 'insensitive' } },
      { description: { contains: keyword, mode: 'insensitive' } },
    ];
  }
  
  // 继续正常查询
  // ...
});
```

## 📊 性能优化

### 1. 使用索引

为常用搜索字段创建索引（在 Prisma Schema 中）:

```prisma
model Product {
  id        String   @id @default(uuid())
  name      String
  status    String
  price     Float
  createdAt DateTime @default(now())

  @@index([name])       // 文本搜索
  @@index([status])     // 精确匹配
  @@index([price])      // 范围查询
  @@index([createdAt])  // 日期范围
}
```

### 2. 限制搜索范围

避免全表扫描:

```javascript
// ✅ 好: 组合索引字段搜索
{ status: 'active', name: { contains: 'test', mode: 'insensitive' } }

// ❌ 差: 只用模糊搜索(可能无索引)
{ description: { contains: 'test', mode: 'insensitive' } }
```

### 3. 合理使用模糊搜索

```javascript
// ✅ 好: 精确字段用 exact
{ status: 'active' }  // exact 模式

// ❌ 差: 固定值用 like
{ status: { contains: 'active', mode: 'insensitive' } }  // like 模式(性能差)
```

## 🎯 最佳实践

### 1. 选择合适的搜索模式

| 字段类型 | 推荐模式 |
|---------|---------|
| 文本(名称、描述) | `like` |
| 状态、分类 | `exact` |
| 标签、多选 | `in` |
| 日期、价格 | `range` |
| 数字比较 | `gt`, `gte`, `lt`, `lte` |

### 2. 搜索字段优先级

```javascript
// P0: 必须支持搜索
- 名称、标题 (like)
- 状态、分类 (exact)
- 日期范围 (range)

// P1: 建议支持搜索
- 标签 (in)
- 价格范围 (range)
- 创建人 (exact)

// P2: 可选搜索
- 描述 (like)
- 备注 (like)
```

### 3. 用户体验优化

```javascript
{
  key: 'name',
  search: {
    enabled: true,
    mode: 'like',
    placeholder: 'Search by name...',  // 清晰的提示
  },
}

{
  key: 'status',
  search: {
    enabled: true,
    mode: 'exact',
    placeholder: 'All',  // 默认选项提示
  },
}
```

## 💡 常见问题

### Q1: 如何实现多字段联合搜索?

```javascript
// 在 Server Action 中自定义
export const getListAction = wrapAction('sysQueryProductList', async (params) => {
  const { whereJson = {} } = params;
  
  if (whereJson.keyword) {
    const keyword = whereJson.keyword;
    delete whereJson.keyword;
    
    whereJson.OR = [
      { name: { contains: keyword, mode: 'insensitive' } },
      { sku: { contains: keyword, mode: 'insensitive' } },
      { description: { contains: keyword, mode: 'insensitive' } },
    ];
  }
  
  // ...
});
```

### Q2: 如何实现高级筛选?

可以在 `customToolbarButtons` 中添加高级筛选按钮，打开自定义筛选 Modal。

### Q3: 搜索性能差怎么办?

1. 为搜索字段创建数据库索引
2. 避免过度使用模糊搜索
3. 使用 PostgreSQL 全文搜索
4. 考虑使用 Elasticsearch
