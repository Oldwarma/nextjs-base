## 📝 文本类字段

### text - 单行文本

最常用的字段类型，用于输入短文本。

```javascript
{
  key: 'name',
  title: 'Name',
  type: 'text',
  table: {
    width: 200,
    copyable: true,        // 显示复制按钮
    ellipsis: true,        // 超长省略
  },
  form: {
    required: true,
    placeholder: 'Enter name',
    fieldProps: {
      maxLength: 50,
      showCount: true,     // 显示字符计数
    },
  },
  search: {
    enabled: true,
    mode: 'like',          // 模糊搜索
  },
}
```

**效果**:
- **表格**: 显示文本，可复制
- **表单**: Input 输入框，显示字符计数
- **搜索**: 模糊搜索

---

### textarea - 多行文本

用于输入长文本、描述信息。

```javascript
{
  key: 'description',
  title: 'Description',
  type: 'textarea',
  table: {
    width: 300,
    ellipsis: true,
    render: (text) => (
      <div style={{ maxHeight: 100, overflow: 'auto' }}>
        {text}
      </div>
    ),
  },
  form: {
    fieldProps: {
      rows: 4,
      maxLength: 500,
      showCount: true,
    },
  },
}
```

**效果**:
- **表格**: 显示文本，超长省略
- **表单**: TextArea 多行输入框
- **搜索**: 不建议启用（文本太长）

---

### password - 密码输入

用于密码字段，表格中不显示。

```javascript
{
  key: 'password',
  title: 'Password',
  type: 'password',
  table: false,            // 不在表格中显示
  form: {
    required: true,
    fieldProps: {
      placeholder: 'Enter password',
      autoComplete: 'new-password',
    },
    rules: [
      { min: 8, message: 'At least 8 characters' },
      { 
        pattern: /^(?=.*[a-z])(?=.*[A-Z])(?=.*\d)/,
        message: 'Must contain uppercase, lowercase, and number',
      },
    ],
  },
}
```

**效果**:
- **表格**: 不显示
- **表单**: Input.Password 密码输入框
- **搜索**: 不适用

## 🔢 数字类字段

### number - 数字输入

用于输入数字，支持小数。

```javascript
{
  key: 'quantity',
  title: 'Quantity',
  type: 'number',
  table: {
    width: 100,
    sorter: true,
  },
  form: {
    required: true,
    fieldProps: {
      min: 0,
      max: 999999,
      precision: 0,        // 整数
      step: 1,
    },
  },
  search: {
    enabled: true,
    mode: 'exact',
  },
}
```

**效果**:
- **表格**: 显示数字，可排序
- **表单**: InputNumber 数字输入框
- **搜索**: 精确匹配

---

## 📊 选择类字段

### select - 下拉选择

最常用的选择组件。

```javascript
{
  key: 'status',
  title: 'Status',
  type: 'select',
  options: [
    { label: 'Active', value: 'active', color: 'green' },
    { label: 'Inactive', value: 'inactive', color: 'red' },
    { label: 'Pending', value: 'pending', color: 'orange' },
  ],
  table: {
    width: 100,
  },
  form: {
    required: true,
    fieldProps: {
      showSearch: true,    // 可搜索
      placeholder: 'Select status',
    },
  },
  search: {
    enabled: true,
    mode: 'exact',
  },
}
```

**多选模式**:

```javascript
{
  key: 'tags',
  title: 'Tags',
  type: 'select',
  options: [
    { label: 'Hot', value: 'hot' },
    { label: 'New', value: 'new' },
    { label: 'Featured', value: 'featured' },
  ],
  form: {
    fieldProps: {
      mode: 'multiple',    // 多选
      maxTagCount: 3,
    },
  },
  search: {
    enabled: true,
    mode: 'in',            // 数组包含查询
  },
}
```

**效果**:
- **表格**: 显示为带颜色的 Tag
- **表单**: Select 下拉选择
- **搜索**: 精确匹配或数组包含

---

### tree-select - 树形选择

用于树形结构数据选择（如分类、部门）。

```javascript
{
  key: 'parent_id',
  title: 'Parent Category',
  type: 'tree-select',
  table: {
    width: 150,
    render: (value, record) => {
      const parent = record.parentInfo;
      return parent ? parent.name : '--- Root ---';
    },
  },
  form: {
    action: getCategoryTreeForSelectAction,  // 自动加载树数据
    placeholder: 'Select parent category',
    fieldProps: {
      treeDefaultExpandAll: true,
      showSearch: true,
      treeNodeFilterProp: 'title',
    },
  },
}
```

**Action 返回格式**:

```javascript
export async function getCategoryTreeForSelectAction() {
  return {
    success: true,
    data: [
      { title: '--- Root ---', value: '', key: '' },
      {
        title: 'Electronics',
        value: 'cat-1',
        key: 'cat-1',
        children: [
          { title: 'Phones', value: 'cat-1-1', key: 'cat-1-1' },
          { title: 'Laptops', value: 'cat-1-2', key: 'cat-1-2' },
        ],
      },
    ],
  };
}
```

**效果**:
- **表格**: 显示父级名称
- **表单**: TreeSelect 树形选择器
- **搜索**: 不建议启用

## ⚡️ 开关类字段

### switch - 开关

用于布尔值（启用/禁用，显示/隐藏等）。

```javascript
{
  key: 'enable',
  title: 'Enabled',
  type: 'switch',

    width: 100,
  },

      checkedChildren: 'Yes',
      unCheckedChildren: 'No',

  search: {
    enabled: true,
    mode: 'exact',
  },
}
```

**效果**:
- **表格**: 显示为 Switch 开关（可直接切换）
- **表单**: Switch 开关
- **搜索**: 精确匹配（true/false）

```javascript
    },

  search: {
    enabled: true,
    mode: 'range',
  },
}
```

**效果**:
- **表格**: 显示为 `2025-01-15`
- **表单**: DatePicker
- **搜索**: 日期范围查询

---

### datetime - 日期时间

用于选择日期和时间。

```javascript
{

  type: 'datetime',

    enabled: true,
    mode: 'range',
```

**效果**:
- **表格**: 显示为 `2025-01-15 14:30:00`
- **表单**: DatePicker (showTime)
- **搜索**: 日期时间范围查询

## 🖼️ 文件类字段

### image - 图片上传

用于上传和显示图片。

```javascript
{
  key: 'avatar',
  title: 'Avatar',
  type: 'image',
  table: {
    width: 80,
    render: (url) => (
      <Avatar src={url} size={50} shape="square" />
    ),
  },
  form: {
    fieldProps: {
      maxCount: 1,
      listType: 'picture-card',
      accept: 'image/*',
    },
  },
}
```

**多图上传**:

```javascript
{
  key: 'images',
  title: 'Product Images',
  type: 'image',
  table: {
    render: (urls) => (
      <Image.PreviewGroup>
        {urls?.map((url, i) => (
          <Image key={i} src={url} width={50} height={50} />
        ))}
      </Image.PreviewGroup>
    ),
  },
  form: {
    fieldProps: {
      maxCount: 5,
      multiple: true,
      listType: 'picture-card',
    },
  },
}
```

**效果**:
- **表格**: 显示缩略图
- **表单**: Upload 上传组件

## 📄 富文本字段

### markdown - Markdown 编辑器

支持 Markdown 语法的编辑器。

```javascript
{
  key: 'content',
  title: 'Content',
  type: 'markdown',
  table: false,  // 不在表格中显示

      height: 400,
      placeholder: 'Enter markdown content',

    render: (text) => (

  },

```

**效果**:
- **表格**: 不显示
- **表单**: Markdown 编辑器

```javascript
  form: {
    placeholder: 'Enter feature',
    fieldProps: {
      addButtonText: 'Add Feature',
      max: 10,
      showCopy: true,
    },
  },
}
```

**效果**:
- **表格**: 显示为 Tag 列表
- **表单**: 可添加/删除的输入框列表

## 🎯 字段配置完整参数

每个字段配置支持以下参数：

```typescript
interface FieldConfig {
  // 基础属性
  key: string;              // 必需：字段名
  title: string;            // 必需：显示标题
  type: string;             // 必需：字段类型
  
  // 表格配置
  table?: {
    width?: number;         // 列宽
    fixed?: 'left' | 'right'; // 固定列
    sorter?: boolean;       // 可排序
    copyable?: boolean;     // 可复制
    ellipsis?: boolean;     // 超长省略
    render?: (value, record) => ReactNode;  // 自定义渲染
  } | false;                // false = 不在表格显示
  
  // 表单配置
  form?: {
    required?: boolean;     // 是否必填
    placeholder?: string;   // 占位符
    fieldProps?: object;    // Ant Design 组件原生属性
    rules?: Rule[];         // 验证规则
    action?: () => Promise; // 数据加载函数（tree-select）
  } | false;                // false = 不在表单显示
  
  // 搜索配置
  search?: {
    enabled: boolean;       // 启用搜索
    mode: 'like' | 'exact' | 'in' | 'range';  // 搜索模式
    placeholder?: string;   // 占位符
  } | false;                // false = 不启用搜索
  
  // 详情显示配置
  detail?: {
    render?: (value) => ReactNode;
  } | false;                // false = 不在详情显示
  
  // 其他
  hideInTable?: boolean;    // 在表格中隐藏
  options?: Array<{         // select/radio 的选项
    label: string;
    value: any;
    color?: string;
  }>;
}
```

## 💡 提示

### 如何选择字段类型？

1. **文本信息** → `text` 或 `textarea`
2. **数字/金额** → `number` 或 `money`
3. **固定选项** → `select` 或 `radio`
4. **树形结构** → `tree-select`
5. **布尔值** → `switch`
6. **日期时间** → `date` 或 `datetime`
7. **图片文件** → `image` 或 `file`
8. **富文本** → `markdown` 或 `richtext`

### 常见组合

```javascript
// 用户头像
{ key: 'avatar', type: 'image' }

// 商品价格
{ key: 'price', type: 'money' }

// 启用状态
{ key: 'enable', type: 'switch' }

// 商品分类
{ key: 'category_id', type: 'tree-select' }

// 文章标签
{ key: 'tags', type: 'select', fieldProps: { mode: 'multiple' } }
```
