## 📦 归档说明

此目录下的文档来自项目的早期版本，主要基于 MongoDB 数据库。在 v3.0.0 版本中，项目已迁移到 PostgreSQL + Prisma。

### 主要变更

| 项目 | v2.x (旧版) | v3.0.0 (新版) |
|:---|:---|:---|
| 数据库 | MongoDB | PostgreSQL |
| ORM | Mongoose | Prisma |
| 主键字段 | `_id` | `id` |
| 命名风格 | snake_case | camelCase |
