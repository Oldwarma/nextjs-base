## 📦 归档说明

此目录下的文档来自项目的早期阶段，主要基于 MongoDB 数据库。开源版本从 `v0.1.0` 起统一基于 PostgreSQL + Prisma。

### 主要变更

| 项目 | 旧版（已归档） | 开源版 (`v0.1.0`) |
|:---|:---|:---|
| 数据库 | MongoDB | PostgreSQL |
| ORM | Mongoose | Prisma |
| 主键字段 | `_id` | `id` |
| 命名风格 | snake_case | camelCase |
