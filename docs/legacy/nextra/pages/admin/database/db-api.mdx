# Prisma 数据库操作指南

> 使用 Prisma ORM 进行类型安全的数据库操作

**Prisma** 是项目的数据库访问层，提供类型安全、自动补全的数据库操作 API。

---

## 🎯 核心特点

- **类型安全**: 自动生成 TypeScript 类型，编译时检查错误
- **自动补全**: IDE 智能提示，减少查阅文档
- **关系查询**: 内置关联数据加载，无需手动 JOIN
- **事务支持**: 支持交互式事务和批量事务
- **迁移管理**: 内置数据库迁移工具

---

## 🚀 快速开始

### 引入方式

```javascript
import { prisma } from '@/lib/database/prisma';
```

### 基础示例

```javascript
'use server';

import { prisma } from '@/lib/database/prisma';

// 创建用户
export async function createUserAction(userData) {
  try {
    const user = await prisma.user.create({
      data: {
        name: userData.name,
        email: userData.email,
        role: 'user',
      },
    });

    return { success: true, data: { userId: user.id } };
  } catch (error) {
    return { success: false, error: error.message };
  }
}

// 查询用户
export async function getUserAction(email) {
  const user = await prisma.user.findUnique({
    where: { email },
  });

  return { success: true, data: user };
}

// 更新用户
export async function updateUserAction(userId, data) {
  await prisma.user.update({
    where: { id: userId },
    data,
  });

  return { success: true };
}

// 删除用户
export async function deleteUserAction(userId) {
  await prisma.user.delete({
    where: { id: userId },
  });

  return { success: true };
}
```

## 📚 API 参考

### 增 (Create)

#### create - 单条记录

```javascript
const user = await prisma.user.create({
  data: {
    name: 'John Doe',
    email: 'john@example.com',
  },
});

// 返回: 新创建的记录对象
```

#### createMany - 批量添加

```javascript
const result = await prisma.user.createMany({
  data: [
    { name: 'Alice', email: 'alice@example.com' },
    { name: 'Bob', email: 'bob@example.com' },
  ],
});

// 返回: { count: 2 }
```

---

### 删 (Delete)

#### delete - 删除单条

```javascript
const deletedUser = await prisma.user.delete({
  where: { id: 'user-id' },
});

// 返回: 被删除的记录
```

#### deleteMany - 批量删除

```javascript
const result = await prisma.user.deleteMany({
  where: {
    createdAt: { lt: new Date('2024-01-01') },
  },
});

// 返回: { count: 10 }
```

---

### 改 (Update)

#### update - 更新单条

```javascript
const user = await prisma.user.update({
  where: { id: 'user-id' },
  data: {
    name: 'John Updated',
    age: 26,
  },
});

// 返回: 更新后的记录
```

#### updateMany - 批量更新

```javascript
const result = await prisma.user.updateMany({
  where: {
    role: 'trial',
    createdAt: { lt: new Date('2024-01-01') },
  },
  data: {
    role: 'user',
  },
});

// 返回: { count: 5 }
```

#### 字段自增/自减

```javascript
// 增加积分
await prisma.user.update({
  where: { id: 'user-id' },
  data: {
    credits: { increment: 100 },
  },
});

// 减少库存
await prisma.product.update({
  where: { sku: 'PROD001' },
  data: {
    stock: { decrement: 1 },
  },
});
```

### 查 (Read)

#### findUnique - 唯一字段查询

```javascript
const user = await prisma.user.findUnique({
  where: { id: 'user-id' },
});

// 或通过唯一字段
const user = await prisma.user.findUnique({
  where: { email: 'john@example.com' },
});

// 返回: 记录对象或 null
```

#### findFirst - 查询第一条

```javascript
const user = await prisma.user.findFirst({
  where: { role: 'admin' },
  orderBy: { createdAt: 'desc' },
});

// 返回: 记录对象或 null
```

#### findMany - 查询列表

```javascript
const users = await prisma.user.findMany({
  where: { role: 'admin' },
  orderBy: { createdAt: 'desc' },
  take: 10,  // 限制条数
});

// 返回: 记录数组
```

#### 分页查询

```javascript
const pageIndex = 1;
const pageSize = 20;

const [users, total] = await Promise.all([
  prisma.user.findMany({
    where: { role: 'user' },
    orderBy: { createdAt: 'desc' },
    skip: (pageIndex - 1) * pageSize,
    take: pageSize,
  }),
  prisma.user.count({
    where: { role: 'user' },
  }),
]);

// 返回分页数据
const result = {
  data: users,
  total,
  page: pageIndex,
  pageSize,
  totalPages: Math.ceil(total / pageSize),
};
```

#### 关联查询

```javascript
// 使用 include 加载关联数据
const order = await prisma.order.findUnique({
  where: { id: 'order-id' },
  include: {
    user: true,           // 加载用户信息
    items: {              // 加载订单项
      include: {
        product: true,    // 嵌套加载产品
      },
    },
  },
});

// order.user = { id, name, email }
// order.items = [{ id, productId, quantity, product: {...} }]
```

#### 选择特定字段

```javascript
const users = await prisma.user.findMany({
  select: {
    id: true,
    name: true,
    email: true,
    // 不返回 password 等敏感字段
  },
});
```

## 💡 实战示例

### 示例 1: 用户注册

```javascript
'use server';

import { prisma } from '@/lib/database/prisma';

export async function registerAction(userData) {
  try {
    // 1. 检查邮箱是否已存在
    const existing = await prisma.user.findUnique({
      where: { email: userData.email },
    });

    if (existing) {
      return { success: false, error: 'Email already registered' };
    }

    // 2. 创建用户
    const user = await prisma.user.create({
      data: {
        username: userData.username,
        email: userData.email,
        password: await hashPassword(userData.password),
        role: 'user',
        credits: 0,
      },
    });

    return { success: true, data: { userId: user.id } };
  } catch (error) {
    return { success: false, error: error.message };
  }
}
```

### 示例 2: 积分充值（事务）

```javascript
'use server';

import { prisma } from '@/lib/database/prisma';

export async function rechargeCreditsAction(packageId) {
  const session = await auth.api.getSession();
  
  try {
    // 使用事务确保数据一致性
    const result = await prisma.$transaction(async (tx) => {
      // 1. 获取套餐信息
      const pkg = await tx.package.findUnique({
        where: { id: packageId, enabled: true },
      });

      if (!pkg) {
        throw new Error('Package not found');
      }

      // 2. 增加用户积分
      const user = await tx.user.update({
        where: { id: session.user.id },
        data: {
          credits: { increment: pkg.credits },
        },
      });

      // 3. 记录交易
      const transaction = await tx.creditTransaction.create({
        data: {
          userId: session.user.id,
          type: 'recharge',
          amount: pkg.credits,
          packageId: pkg.id,
          price: pkg.price,
        },
      });

      return { user, transaction };
    });

    return { success: true, data: result };
  } catch (error) {
    return { success: false, error: error.message };
  }
}
```

### 示例 3: 数据统计面板

```javascript
'use server';

import { prisma } from '@/lib/database/prisma';

export async function getDashboardStatsAction() {
  try {
    const today = new Date(new Date().setHours(0, 0, 0, 0));

    // 并行查询
    const [
      totalUsers,
      todayNewUsers,
      orderStats,
      recentOrders,
    ] = await Promise.all([
      prisma.user.count(),
      prisma.user.count({
        where: { createdAt: { gte: today } },
      }),
      prisma.order.aggregate({
        where: { status: 'paid' },
        _sum: { amount: true },
        _avg: { amount: true },
      }),
      prisma.order.findMany({
        where: { status: 'paid' },
        orderBy: { createdAt: 'desc' },
        take: 10,
        include: { user: { select: { name: true } } },
      }),
    ]);

    return {
      success: true,
      data: {
        totalUsers,
        todayNewUsers,
        totalRevenue: orderStats._sum.amount || 0,
        avgOrderAmount: orderStats._avg.amount || 0,
        recentOrders,
      },
    };
  } catch (error) {
    return { success: false, error: error.message };
  }
}
```

## 最佳实践

### 1. 错误处理

```javascript
// 始终使用 try-catch
export async function myAction() {
  try {
    const result = await prisma.user.findUnique({
      where: { email: 'test@example.com' },
    });
    return { success: true, data: result };
  } catch (error) {
    console.error('myAction error:', error);
    return { success: false, error: error.message };
  }
}
```

### 2. 使用事务

```javascript
// 多个相关操作使用事务
const result = await prisma.$transaction(async (tx) => {
  const user = await tx.user.create({ data: userData });
  const profile = await tx.profile.create({ 
    data: { userId: user.id, ...profileData } 
  });
  return { user, profile };
});
```

### 3. 选择性加载

```javascript
// 只返回需要的字段
const users = await prisma.user.findMany({
  select: {
    id: true,
    name: true,
    email: true,
    // 不返回 password 等敏感字段
  },
});
```

### 4. 批量操作

```javascript
// ✅ 使用批量操作
await prisma.user.updateMany({
  where: { id: { in: userIds } },
  data: { status: 'active' },
});

// ❌ 避免循环调用
for (const userId of userIds) {
  await prisma.user.update({ where: { id: userId }, data: { status: 'active' } });
}
```

### 5. 利用 Prisma 中间件

```javascript
// 在 prisma.js 中配置中间件
prisma.$use(async (params, next) => {
  // 自动添加 updatedAt
  if (params.action === 'update' || params.action === 'updateMany') {
    params.args.data.updatedAt = new Date();
  }
  return next(params);
});
```

Prisma 的核心优势:

- 类型安全的数据库操作

**使用建议**:

- 简单场景直接使用 Prisma Client
- 复杂业务逻辑使用 BaseDAO 封装
- 始终使用事务处理相关联的操作
