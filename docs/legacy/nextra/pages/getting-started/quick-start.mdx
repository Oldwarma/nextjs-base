# 快速开始

> 5 分钟创建你的第一个 CRUD 管理页面

本教程将带你从零开始，创建一个完整的产品管理页面，包括列表、创建、编辑、删除等功能。

## 前置要求

- 安装 Node.js 18+
- 配置 PostgreSQL 数据库
- 克隆或下载了 NextJS Base Framework

如果还未安装，请先查看 [安装指南](/getting-started/installation)。

## 步骤 1: 创建 Server Actions

Server Actions 是后端逻辑层，负责处理数据库操作和业务逻辑。

创建文件 `app/(admin)/actions/rbac/crud-action.product.js`:

```javascript filename="app/(admin)/actions/rbac/crud-action.product.js" {3,7,11,15}
'use server';

import { auth } from '@/lib/auth/auth';
import { headers } from 'next/headers';
import { wrapQueryAction } from '@/lib/core/action-wrapper';

// 权限检查函数
async function checkBackendAccess() {
  const session = await auth.api.getSession({
    headers: await headers(),
  });

  if (!session?.user || !session.user.isBackendAllowed) {
    return { hasAccess: false, error: 'Unauthorized' };
  }

  return { hasAccess: true };
}

/**
 * 获取产品列表
 */
export const getProductListAction = wrapQueryAction('product', async (params = {}) => {
  const { pageIndex = 1, pageSize = 20, whereJson = {}, sortJson = { createdAt: 'desc' } } = params;

  const { prisma } = await import('@/lib/database/prisma');

  const skip = (pageIndex - 1) * pageSize;
  const [data, total] = await Promise.all([
    prisma.product.findMany({
      where: whereJson,
      orderBy: sortJson,
      skip,
      take: pageSize,
    }),
    prisma.product.count({ where: whereJson }),
  ]);

  return {
    success: true,
    data,
    total,
    page: pageIndex,
    pageSize,
  };
});

/**
 * 创建产品
 */
export async function createProductAction(data) {
  const backendCheck = await checkBackendAccess();
  if (!backendCheck.hasAccess) {
    return { success: false, error: backendCheck.error };
  }

  const { prisma } = await import('@/lib/database/prisma');

  const newProduct = await prisma.product.create({
    data: {
      ...data,
      id: crypto.randomUUID(),
      createdAt: new Date(),
      updatedAt: new Date(),
    },
  });

  return { success: true, data: newProduct };
}

/**
 * 更新产品
 */
export async function updateProductAction(id, data) {
  const backendCheck = await checkBackendAccess();
  if (!backendCheck.hasAccess) {
    return { success: false, error: backendCheck.error };
  }

  const { prisma } = await import('@/lib/database/prisma');

  const result = await prisma.product.update({
    where: { id },
    data: { ...data, updatedAt: new Date() },
  });

  if (!result) {
    return { success: false, error: 'Product not found' };
  }

  return { success: true, data: result };
}

/**
 * 删除产品
 */
export async function deleteProductAction(id) {
  const backendCheck = await checkBackendAccess();
  if (!backendCheck.hasAccess) {
    return { success: false, error: backendCheck.error };
  }

  const { prisma } = await import('@/lib/database/prisma');

  await prisma.product.delete({
    where: { id },
  });

  return { success: true, message: 'Product deleted successfully' };
}
```

### 代码说明

1. **权限检查**: `checkBackendAccess()` 确保只有登录的管理员才能操作
2. **列表查询**: `getProductListAction` 使用 `wrapQueryAction` 包装，自动处理日志记录
3. **CRUD 操作**: 创建、更新、删除都是标准的 Prisma 操作
4. **UUID 主键**: 使用 `crypto.randomUUID()` 生成唯一 ID
5. **时间戳**: 自动添加 `createdAt` 和 `updatedAt`

## 步骤 2: 创建前端页面

前端页面使用 `SmartCrudPage` 组件，通过配置自动生成表格、表单、搜索。

创建文件 `app/(admin)/admin/products/page.js`:

```javascript filename="app/(admin)/admin/products/page.js" {10-42,45-52}
'use client';

import { useMemo } from 'react';
import dynamic from 'next/dynamic';
import * as productActions from '@/app/(admin)/actions/rbac/crud-action.product';

const SmartCrudPage = dynamic(() => import('@/components/admin/smart-crud-page'), {
  ssr: false,
});

export default function ProductsPage() {
  // ============================================
  // 字段配置
  // ============================================
  const fieldsConfig = useMemo(
    () => [
      {
        key: 'name',
        title: 'Product Name',
        type: 'text',
        table: {
          width: 200,
          copyable: true,
        },
        form: {
          required: true,
          placeholder: 'Enter product name',
        },
        search: {
          enabled: true,
          mode: 'like', // 模糊搜索
        },
      },
      {
        key: 'price',
        title: 'Price',
        type: 'number',
        table: {
          width: 120,
          sorter: true,
        },
        form: {
          required: true,
          placeholder: 'Enter price',
          fieldProps: {
            min: 0,
            precision: 2,
          },
        },
      },
      {
        key: 'status',
        title: 'Status',
        type: 'select',
        options: [
          { label: 'Active', value: 'active', color: 'green' },
          { label: 'Inactive', value: 'inactive', color: 'red' },
        ],
        table: {
          width: 100,
        },
        form: {
          required: true,
        },
        search: {
          enabled: true,
          mode: 'exact', // 精确匹配
        },
      },
      {
        key: 'description',
        title: 'Description',
        type: 'textarea',
        table: {
          width: 300,
          ellipsis: true,
        },
        form: {
          fieldProps: {
            rows: 4,
          },
        },
      },
      {
        key: 'stock',
        title: 'Stock',
        type: 'number',
        table: {
          width: 100,
        },
        form: {
          required: true,
          fieldProps: {
            min: 0,
          },
        },
      },
      {
        key: 'category',
        title: 'Category',
        type: 'select',
        options: [
          { label: 'Electronics', value: 'electronics' },
          { label: 'Clothing', value: 'clothing' },
          { label: 'Food', value: 'food' },
          { label: 'Books', value: 'books' },
        ],
        table: {
          width: 120,
        },
        form: {
          required: true,
        },
        search: {
          enabled: true,
        },
      },
      {
        key: 'createdAt',
        title: 'Created At',
        type: 'datetime',
        table: {
          width: 180,
          sorter: true,
        },
        form: false, // 不在表单中显示
      },
    ],
    []
  );

  // ============================================
  // Actions 配置
  // ============================================
  const actions = {
    getList: productActions.getProductListAction,
    create: productActions.createProductAction,
    update: productActions.updateProductAction,
    delete: productActions.deleteProductAction,
  };

  // ============================================
  // 返回页面
  // ============================================
  return (
    <SmartCrudPage
      fieldsConfig={fieldsConfig}
      actions={actions}
      title="Product Management"
      rowKey="id"
      enableCreate={true}
      enableEdit={true}
      enableDelete={true}
      formProps={{
        width: 600,
      }}
    />
  );
}
```

### 字段配置说明

每个字段配置包含以下部分：

- **key**: 字段名（对应数据库字段）
- **title**: 显示标题
- **type**: 字段类型（`text`, `number`, `select`, `textarea`, `datetime` 等）
- **table**: 表格显示配置
  - `width`: 列宽
  - `copyable`: 是否可复制
  - `sorter`: 是否可排序
  - `ellipsis`: 超长省略
- **form**: 表单配置
  - `required`: 是否必填
  - `placeholder`: 占位符
  - `fieldProps`: Ant Design 组件原生属性
- **search**: 搜索配置
  - `enabled`: 启用搜索
  - `mode`: 搜索模式（`like` 模糊搜索, `exact` 精确匹配）

## 常见问题

### Q: 如何修改表格的默认排序？

在 `getProductListAction` 中修改 `sortJson` 默认值：

```javascript
const { sortJson = { price: -1 } } = params; // 按价格降序
```

### Q: 如何添加更多字段？

在 `fieldsConfig` 数组中添加新的字段配置即可：

```javascript
{
  key: 'brand',
  title: 'Brand',
  type: 'text',
  table: { width: 120 },
  form: { required: true },
}
```

### Q: 如何自定义表格渲染？

使用 `table.render` 函数：

```javascript
{
  key: 'price',
  title: 'Price',
  type: 'number',
  table: {
    render: (value) => `$${value.toFixed(2)}`,
  },
}
```

### Q: 如何添加批量操作？

参考 [高级功能 - 批量操作](/admin/smart-crud/advanced#batch-operations)。
